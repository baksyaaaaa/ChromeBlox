# GitHub mods

Anything in this folder syncs to Chrome Blox on every launch and gets copied over Roblox's own files.
Use the same layout as the Roblox client, for example:

- `mods/content/sounds/ouch.ogg` → death sound
- `mods/content/textures/Cursors/KeyboardMouse/ArrowCursor.png` → cursor
- `mods/content/sky/...` → default skybox

Delete a file here and it's removed from your PC on the next launch.
Your local mods folder (Mods tab → Open mods folder) still wins if both have the same file.
